### Контрольные вопросы

## 1. Что такое IL и зачем он нужен между C# и машинным кодом? 
IL это промежуточный код. Он служит посредником чтобы код работал не зависимо от архитектуры, кода и т.п.

## 2.  Почему .dll можно декомпилировать?  
В .dll сохраняется много метаданных и конструкций. Декомпилятор берет IL код и пытается реконструировать код используя эти данные.

## 3.  Какие отличия Debug и Release вы увидели в IL?
в Debug сохряняеться много доп информации а в Release применятся оптимизация и некоторые переменные могут исчезнуть так же упрощаются выражения и отладочаня информация удаляется 

## 4.  Почему Release обычно быстрее Debug? 
Release быстрее потому что меньше проверок во время выполнения, оптимизированный код ,отсутствие отладочных инструкций, устранение избыточных операций с памятью

## 5.  Почему строковый пароль в .dll нельзя считать защищённым? 
строковый пароль в .dll нельзя считать защищенным потому что код могут восстановить и данные утекут
